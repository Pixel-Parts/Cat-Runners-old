# Cat-Runners
 
### ⚠️ Disclaimer: "The Learning Curve"
Dies ist eines meiner ersten Projekte aus dem Jahr 2021. Der Code ist nach heutigen Maßstäben unordentlich und nicht nach dem SOLID-Prinzip aufgebaut. 

**Warum ich es trotzdem zeige?**
* **Proof of Concept:** Es war mein Einstieg in C# und die Unity Engine.
* **Lerneffekt:** An diesem Projekt habe ich verstanden wie Game-Code und Unity überhaupt in irgendeiner Weise funktionieren.
* **Autodidaktik:** Alles hier entstand ohne professionelle Hand durch reines "Trial & Error", einen Haufen Tutorials und Debugging.

### Features
* Voll funktionsfähiger Game-Loop in C#.
* Einfaches UI-System und unfertiger Score-Logik.
* Integration von Android-Touch-Input.

*Hinweis: Ich lasse dieses Repository in seinem ursprünglichen Zustand, um meinen Fortschritt in der Softwareentwicklung dokumentierbar zu machen.*
